### Added
- **Clean up database drift from Settings** (#3357). After "Check database" finds rows that point at a parent that was deleted, a "Preview cleanup" button shows what would happen to each relationship: rows whose parent should have cascaded are deleted, references that should have been cleared are cleared, and anything else is left alone. Nothing changes until you confirm. Bindery saves a backup of the database first and tells you where it is, and if the backup fails nothing is touched. It then checks again and shows what is left. Admins only, one run at a time, and Bindery keeps answering while it works. `bindery db-repair` is still there for an instance that will not start.
