### Added
- **Ebook content check at import** (#3015). When a download finishes, Bindery now compares the EPUB's own title and author with the book it was grabbed for. Only a definite mismatch counts, meaning the title differs (series suffixes such as `, Book 11` and subtitles are ignored) and the author is neither the book's author nor one of its aliases, so a pen name like Franklin W. Dixon for Leslie McFarlane still matches. A file with no title or author is never flagged. The new setting **Check ebook contents** (`import.ebook.content_check`, admin only, in Settings under General) is `off`, `warn` or `block` and defaults to `warn`: the file imports as before and the History row and webhook carry a `contentCheck` note saying what the file turned out to be. `block` is opt in and refuses the download the way a wrong language does, blocklisting the release and keeping the book Wanted. Match to book and manual import skip the check, and Retry import runs it again.
