### Added
- **Link-local service URLs can be allowed** (#2036). `BINDERY_ALLOW_LINK_LOCAL_SERVICES=1` is an opt in that lets the service URLs you type (indexers, Prowlarr, download clients, Audiobookshelf, Grimmory, the Calibre plugin) use link-local addresses. This is what rootless Podman with pasta networking needs, since the host is only reachable at 169.254.1.2 there. It is off by default, cloud metadata addresses stay blocked even when it is on, and indexer download links, covers and webhooks are unaffected. The refusal message now names the variable. Thanks to seannymurrs for the report.
