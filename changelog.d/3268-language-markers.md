### Fixed
- **More foreign audiobook releases are recognised by their name** (#3268). The mangled German markers `ungekrzt` and `gekrzt`, where an indexer dropped the umlaut, now count as German. A scene release that puts its language code before the format marker, such as `Author-Title-DE-AUDIOBOOK-4CD-FLAC-2005-GROUP` or `Author-Title-2MP3CD-DE-2005-GROUP`, is read too, so an English only profile no longer grabs it. Only scene shaped names are read this way, and spaced names such as `Stephen King - Audiobook - IT 2017` or `read by Robert De Niro` no longer pick up a language from a stray word.
