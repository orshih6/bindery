### Fixed
- **Fix match and manual import no longer say a file is outside your library when it is simply gone** (discussion #3332). If the database remembered a file that had since been moved, renamed or lost to an unmounted drive, the Reassign file modal and the other manual import screens answered `path is outside the configured library roots` while listing the very folder that held it. They now say `Bindery cannot read this file` with the file name and what to check. A file that really is outside your library, or a link that points out of it, still gets the old message. Thanks to niddelicious for the report.
